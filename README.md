# AccessAI

AI-powered accessibility support for everyday digital information.

## Overview

AccessAI helps users understand images, audio, video, and complex digital service text by converting them into structured, accessible content. The product is designed for users with visual, hearing, and cognitive accessibility needs.

## Phase 1

This repository currently contains the architecture and project foundation only. The app will be expanded in later phases after verification.

## Project structure

- `backend/` — FastAPI API, AI service layer, validation, and demo logic
- `frontend/` — React + Vite + TypeScript interface
- `.env.example` — environment configuration template
- `docker-compose.yml` — optional local service orchestration
